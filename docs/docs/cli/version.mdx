# homebutler version

Prints the homebutler version, build date, and Go version.

```bash
homebutler version [flags]
```

The output is plain text. `--json` has no effect on this command.

## Examples

```bash
homebutler version
```

```text
homebutler 1.8.0 (built 2026-11-11T09:52:31Z, go1.26.10)
```
